Architecture · Protocol V2 · ForwardMesh

Source-routed cut-through file mesh

Files traverse an arbitrary chain of fwdd nodes over big-endian Protocol V2 TCP streams: intermediate hops decrement TTL and pipe 64 KB chunks with zero disk I/O unless single-pass tee caching is requested, verifying IEEE 802.3 CRC32 at every stage.

DATA PLANE

Cut-through streaming & single-pass tee

  • kFlagNone (0x00) streams sockets end-to-end via RelayStream() in 64 KB buffers with zero intermediate disk writes
  • -s (kFlagStoreOnHop) or daemon -S tees bytes to .fwd_tee_XXXXXX in one pass
  • Symmetric support for multi-hop ForwardPush (1) and reverse-streamed ForwardPull (0)

WIRE PROTOCOL V2

Source-routed header consumption

  • Big-endian frame: ForwardHead (28B) + ForwardNode[ttl] + ForwardFile + data
  • uint64_t packet & file lengths lift the 4 GB ceiling; magic 0xFF44AADD, max TTL 32
  • Each relay hop consumes nodes[0], decrements ttl, and trims 8B from length

RELIABILITY & OPS

In-flight CRC32 & daemon model

  • IEEE 802.3 crc32 checked in-flight on hops and before atomic rename() (retcode = 6 on tamper)
  • Pre-fork() socket bind, poll() accept loop + worker pool, and 30s socket timeouts
  • Path-traversal guard (IsSafeRelativePath) and 64-bit request id across logs
